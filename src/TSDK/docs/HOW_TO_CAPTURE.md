# 📸 抓包操作详细图文教程

## 🎯 目标

抓取**兑换商品**时的网络请求数据

---

## 🛠️ 准备工作

### 1. 使用Chrome浏览器
- ✅ Google Chrome
- ✅ Microsoft Edge
- ✅ 其他基于Chromium的浏览器

### 2. 确保已登录淘宝账号

---

## 📝 详细步骤

### 第一步: 打开开发者工具

```
方式1: 按键盘快捷键
- Windows: F12 或 Ctrl + Shift + I
- Mac: Cmd + Option + I

方式2: 右键菜单
- 在页面空白处右键
- 选择 "检查" 或 "Inspect"
```

✅ **检查点:** 浏览器底部或右侧应该出现开发者工具面板

---

### 第二步: 切换到Network标签

```
1. 在开发者工具顶部找到 "Network" 标签
2. 点击切换到Network面板
3. 如果看到提示 "Recording network activity..."，说明已就绪
```

✅ **检查点:** Network标签应该是高亮/选中状态

---

### 第三步: 设置保留日志

```
在Network标签中找到并勾选:
☑️ Preserve log (保留日志)

作用: 防止页面刷新时清空请求记录
```

**重要提示:** 这一步非常关键，否则可能抓不到数据！

---

### 第四步: 访问礼享金页面

```
在浏览器地址栏输入:
https://pages.tmall.com/wow/z/m/hdwh/2024act

或者:
1. 打开手机淘宝App
2. 搜索 "礼享金"
3. 复制页面链接到电脑浏览器
```

✅ **检查点:** Network标签开始显示请求记录

---

### 第五步: 清空现有记录（可选）

```
点击Network标签左上角的 🚫 图标（禁止符号）
或按快捷键: Ctrl + E (Windows) / Cmd + E (Mac)

作用: 清空之前的请求，方便找到目标请求
```

---

### 第六步: 执行兑换操作

```
1. 在礼享金页面找到任意一个可兑换商品
   例如: "type-c数据线 (0.5礼享金)"
   
2. 点击商品下方的 "立即兑换" 按钮
   
3. 如果弹出确认框，点击 "确定" 或 "确认兑换"
```

**注意:**
- ✅ 可以兑换最便宜的商品（0.5礼享金）
- ✅ 即使礼享金不足也没关系，请求数据依然有效
- ✅ 兑换失败的错误响应也很有价值

---

### 第七步: 找到目标请求

在Network标签中找到名称包含以下内容的请求:

```
🎯 目标请求名称:
mtop.fission.gift.share.vcoin.exchange

⚠️ 注意区分:
❌ mtop.fission.gift.share.vcoin.exchange.allpage  (这是商品列表，不是兑换)
✅ mtop.fission.gift.share.vcoin.exchange          (这才是兑换接口)
```

**技巧:** 
```
1. 在Filter输入框输入: exchange
2. 按时间排序，最新的在最上面
3. 查看Method列，可能是POST或GET
```

---

### 第八步: 复制请求数据

#### 方法A: 复制cURL（最推荐）⭐⭐⭐

```
1. 在Network中找到目标请求
2. 右键点击该请求
3. 选择 Copy → Copy as cURL (bash)
4. 粘贴到文本编辑器
5. 发送给我
```

**示例输出:**
```bash
curl 'https://h5api.m.tmall.com/h5/mtop.fission.gift.share.vcoin.exchange/1.0/...' \
  -H 'cookie: xxx' \
  -H 'content-type: xxx' \
  --data-raw 'xxx'
```

---

#### 方法B: 手动复制详细信息

如果cURL复制失败，可以手动复制：

**8.1 复制请求头 (Headers)**
```
1. 点击目标请求
2. 右侧面板切换到 "Headers" 标签
3. 找到 "Request Headers" 部分
4. 点击 "view source" 或 "view parsed"
5. 全选复制
```

**8.2 复制请求数据 (Payload)**
```
1. 切换到 "Payload" 标签（如果是POST请求）
2. 找到 "Form Data" 或 "Request Payload"
3. 点击 "view source"
4. 全选复制
```

**8.3 复制响应数据 (Response)**
```
1. 切换到 "Response" 标签
2. 全选复制响应内容
3. 通常是JSON格式
```

---

#### 方法C: 导出HAR文件（最完整）⭐⭐

```
1. 在Network标签的请求列表中右键
2. 选择 "Save all as HAR with content"
3. 保存.har文件
4. 将文件发送给我
```

**优点:** 包含所有请求的完整信息

---

### 第九步: 提交数据

```

或

[粘贴请求头]

[粘贴请求数据]

[粘贴响应数据]

===============================
```

## 🎯 如果要抓取提现接口

重复上述步骤，但在第六步改为:

```
1. 在礼享金页面找到 "提现" 或 "现金兑换" 模块
2. 选择一个提现档位（如: 1元、3元、5元）
3. 点击 "立即兑换" 或 "确认提现"

5. 按照相同方式复制数据
```

## ❓ 常见问题解答

### Q1: Network标签是空的？
```
A: 
1. 检查是否勾选了 "Preserve log"
2. 刷新页面重新操作
3. 检查开发者工具是否在操作前就打开了
```

### Q2: 找不到目标请求？
```
A:
1. 在Filter中输入 "mtop" 过滤无关请求
2. 或输入 "exchange" 精确查找
3. 按时间降序排列，最新的在最上面
4. 查看所有包含 "h5api.m.tmall.com" 的请求
```

### Q3: 请求很多，不知道哪个是？
```
A:
1. 清空Network后再操作一次
2. 观察点击兑换按钮后立即出现的请求
3. 查看URL中包含 "exchange" 的
4. 查看Method列为POST的（兑换一般是POST）
```

### Q4: 兑换失败了怎么办？
```
A:
✅ 没关系！失败的请求数据也是有效的
✅ 错误响应对我分析也很有帮助
✅ 可以提供失败时的Response数据
```

### Q5: 担心Cookie泄露？
```
A:
1. 可以用测试账号操作
2. 或手动删除Cookie中的敏感部分
3. 我只需要请求的格式和参数结构
4. 可以把具体的值替换为 "***"
```

### Q6: 复制为cURL后是Windows的格式（带^符号）？
```
A:
✅ 没关系，Windows和Linux的cURL我都能解析
✅ 直接发送即可
```
