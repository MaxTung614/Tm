========================================
  天猫礼享金抢购系统 v1.0.0
========================================

欢迎使用天猫礼享金抢购系统！

本软件是一个自动化抢购工具，支持多账号管理、定时任务和实时监控。


📦 文件说明
========================================

TmallGiftSnatcher.exe   - 主程序（双击启动）
data/                    - 数据目录
├── risk_params.json    - 风控参数配置
└── logs/               - 日志文件（自动生成）


🚀 快速开始
========================================

1. 双击 TmallGiftSnatcher.exe 启动程序

2. 浏览器会自动打开（http://localhost:5173）

3. 首次使用需要配置风控参数：
   - 点击"设置" → "参数提取"
   - 按照页面提示提取参数
   
4. 添加账号：
   - 点击"账号管理" → "添加账号"
   - 扫描二维码登录
   
5. 创建抢购任务：
   - 点击"任务管理" → "创建任务"
   - 设置抢购时间和商品
   
6. 开始抢购！


⚙️ 系统要求
========================================

操作系统: Windows 10/11 (64位)
内存: 4GB 或更高
磁盘空间: 200MB 可用空间
网络: 稳定的互联网连接


💡 重要提示
========================================

1. 首次使用必须提取风控参数（UMID Token）
   否则抢购功能无法正常工作

2. Cookie 会自动保存，定期检查是否过期

3. 建议使用稳定的网络环境，避免抢购失败

4. 不要频繁抢购，避免触发风控

5. 本软件仅供学习研究使用，请遵守平台规则


🔧 风控参数提取
========================================

方法一：自动提取（推荐）

1. 打开系统，进入"设置" → "参数提取"
2. 点击"自动提取"按钮
3. 按照提示在手机淘宝中操作
4. 等待提取完成

方法二：手动配置

1. 用电脑浏览器打开淘宝网并登录
2. 按 F12 打开开发者工具
3. 刷新页面，查找 mtop 请求
4. 复制 User-Agent 和 umidToken
5. 在"设置"中手动填入

❓ 常见问题
========================================

Q: 无法启动程序？
A: 检查是否被杀毒软件拦截，添加信任即可

Q: 扫码登录失败？
A: 确认网络连接正常，使用手机淘宝扫码

Q: 抢购一直失败？
A: 检查风控参数是否正确，尝试重新提取

Q: Cookie 过期怎么办？
A: 在账号管理中重新扫码登录

Q: 支持哪些商品？
A: 目前仅支持天猫礼享金（红包）
