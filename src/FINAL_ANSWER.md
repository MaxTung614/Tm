## ✅ 完整解答

### **问题 1：不同设备必须重新提取吗？**

**答案：是的，但现在有3种超简单的提取方法！**

#### **原因：**
```
设备A的参数：
- umidToken: 绑定设备A的唯一标识
- ua: 设备A的指纹信息

设备B的参数：
- umidToken: 绑定设备B的唯一标识（与设备A不同）
- ua: 设备B的指纹信息（与设备A不同）

❌ 设备B不能用设备A的参数
✅ 每个设备需要自己的参数
```

#### **但是！** 
同一设备的所有账号可以共享参数：
```
设备A + 参数A → 账号1, 账号2, 账号3 ✅
设备B + 参数B → 账号4, 账号5 ✅
```

```

总耗时：5秒
手动操作：0次
```

### **方法 2：浏览器控制台提取** ⭐⭐⭐⭐

**适合自动提取失败时使用，30秒完成**

#### **步骤：**

```
1. 按 F12 打开开发者工具
2. 切换到 Console 标签
3. 粘贴以下代码并回车：
```

```javascript
// 复制这段代码
(function() {
  const umidToken = document.cookie
    .split('; ')
    .find(row => row.startsWith('_m_h5_tk='))
    ?.split('=')[1] || 'not found';
  
  const ua = navigator.userAgent;
  
  const config = {
    umidToken: umidToken,
    ua: ua,
    asac: '2A21B24LA1SI0HB0EEVN03'
  };
  
  console.log('='.repeat(50));
  console.log('风控参数：');
  console.log(JSON.stringify(config, null, 2));
  console.log('='.repeat(50));
  
  copy(JSON.stringify(config, null, 2));
  console.log('✅ 已复制到剪贴板！');
})();
```

```
4. 查看控制台输出
5. 配置已自动复制到剪贴板
6. 粘贴到系统中
```

| ua | 很少 | 基本不需要 |
| Cookie | 1-7天 | 每个账号独立更新 |
