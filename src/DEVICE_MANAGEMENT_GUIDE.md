# 📱 多设备管理完整指南

## 🎯 核心问题

**问题：** 不同设备需要不同的风控参数，怎么方便地提取和管理？

**答案：** 三种方案任选，推荐方案1（自动提取）

---

## 📊 设备与参数的关系

```
设备A (iPhone 15)              设备B (小米14)
    ↓                              ↓
umidToken_A                    umidToken_B
ua_A                          ua_B
    ↓                              ↓
账号1, 账号2, 账号3            账号4, 账号5
```

**规则：**
- ✅ 同一设备的所有账号可以共享风控参数
- ❌ 不同设备必须使用各自的风控参数
- ✅ 系统支持多设备配置管理

## 🚀 方案 1：扫码登录时自动提取（推荐）

### **原理**

扫码登录过程中，系统会：
1. 生成二维码
2. 手机扫码
3. **服务器返回登录信息（包含设备信息）**
4. **自动提取 umidToken 和 ua**
5. 保存到设备配置

### **实现方式**

#### **1. 自动检测提取**

登录成功后，系统自动：
```
1. 从登录响应中提取 umidToken
2. 从请求头中提取 ua
3. 自动关联到当前设备
4. 保存设备配置
```

#### **2. 用户体验**

```
用户扫码登录
    ↓
系统提示："正在提取设备参数..."
    ↓
系统提示："设备参数已自动保存 ✅"
    ↓
可以直接使用，无需手动操作！
```

## 🔄 使用流程

### **场景 1：单设备多账号（简单）**

```
iPhone 15
  ↓ 提取一次参数
  ↓
账号A、B、C 都用这个设备扫码
  ↓
所有账号共享同一套参数
  ↓
完成！
```

**操作：**
1. 提取 iPhone 15 的参数（一次）
2. 账号A、B、C 都用 iPhone 15 扫码
3. 系统自动关联到同一设备
4. 开始使用

---

### **场景 2：多设备多账号（灵活）**

```
iPhone 15              小米14
  ↓                      ↓
提取参数A               提取参数B
  ↓                      ↓
账号A、B                账号C、D
  ↓                      ↓
使用参数A               使用参数B
```

**操作：**

```
# 1. 提取 iPhone 15 参数
设备管理 → 添加设备 → iPhone 15
→ 自动提取或手动输入参数

# 2. 提取小米14 参数  
设备管理 → 添加设备 → 小米14
→ 自动提取或手动输入参数

# 3. 账号关联设备
账号A 扫码时选择 → iPhone 15
账号B 扫码时选择 → iPhone 15
账号C 扫码时选择 → 小米14
账号D 扫码时选择 → 小米14

# 4. 自动使用对应参数
切换到账号A → 自动使用 iPhone 15 的参数
切换到账号C → 自动使用小米14 的参数
```

## 🛠️ 自动提取实现

### **登录时自动提取**

系统会在登录成功后尝试提取参数：

```python
# 登录成功回调
def on_login_success(login_response):
    # 1. 从响应中提取 umidToken
    umid_token = extract_umid_from_response(login_response)
    
    # 2. 从请求头中提取 ua
    ua = extract_ua_from_request()
    
    # 3. 检测设备信息
    device_info = detect_device()
    
    # 4. 保存设备配置
    device_id = save_device_config({
        "umidToken": umid_token,
        "ua": ua,
        "device_info": device_info
    })
    
    # 5. 关联账号到设备
    link_account_to_device(account_id, device_id)
    
    return "参数已自动提取 ✅"
```

## 🔍 浏览器控制台提取方法

### **适用场景**

- 自动提取失败时
- 需要手动验证参数时
- 调试时

### **步骤**

#### **1. 打开开发者工具**

```
Chrome/Edge: F12 或 Ctrl+Shift+I
Safari: Cmd+Option+I
Firefox: F12 或 Ctrl+Shift+K
```

#### **2. 切换到 Console 标签**

#### **3. 粘贴并运行脚本**

```javascript
// 复制这段代码到控制台
(function() {
  // 提取 umidToken
  const umidToken = document.cookie
    .split('; ')
    .find(row => row.startsWith('_m_h5_tk='))
    ?.split('=')[1] || 'not found';
  
  // 提取 ua
  const ua = navigator.userAgent;
  
  // 提取设备信息
  const deviceInfo = {
    platform: navigator.platform,
    vendor: navigator.vendor,
    maxTouchPoints: navigator.maxTouchPoints
  };
  
  // 显示结果
  console.log('='.repeat(50));
  console.log('风控参数提取结果：');
  console.log('='.repeat(50));
  console.log('umidToken:', umidToken);
  console.log('ua:', ua);
  console.log('deviceInfo:', JSON.stringify(deviceInfo, null, 2));
  console.log('='.repeat(50));
  
  // 生成配置
  const config = {
    umidToken: umidToken,
    ua: ua,
    asac: '2A21B24LA1SI0HB0EEVN03',
    deviceInfo: deviceInfo
  };
  
  console.log('完整配置（复制下面的内容）：');
  console.log(JSON.stringify(config, null, 2));
  
  // 复制到剪贴板
  copy(JSON.stringify(config, null, 2));
  console.log('✅ 已复制到剪贴板！');
})();
```

#### **4. 查看结果**

控制台会显示：
```
==================================================
风控参数提取结果：
==================================================
umidToken: T2gArl5MCqpJaBLQXh3b0Xps...
ua: Mozilla/5.0 (iPhone; CPU iPhone OS 18_1...
deviceInfo: {
  "platform": "iPhone",
  "vendor": "Apple Computer, Inc.",
  "maxTouchPoints": 5
}
==================================================
完整配置（复制下面的内容）：
{
  "umidToken": "T2gArl5MCqpJaBLQXh3b0Xps...",
  "ua": "Mozilla/5.0...",
  "asac": "2A21B24LA1SI0HB0EEVN03",
  "deviceInfo": {...}
}
✅ 已复制到剪贴板！
```

#### **5. 保存到系统**

回到系统，粘贴配置即可
