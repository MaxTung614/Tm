## 🎯 问题分析

您遇到的问题是 **Windows 批处理文件字符编码问题**：

```
'妫€鏌?npm' 不是内部或外部命令
```

这是因为：
- 批处理文件使用 UTF-8 编码保存
- Windows 命令行默认使用 GBK/GB2312 编码
- 导致中文字符显示为乱码
- 乱码被当作命令执行，导致错误

## 💡 为什么会出现编码问题？

### 技术原因

```
Windows 批处理文件编码问题：

1. Windows 命令行默认编码：GBK (Code Page 936)
2. 现代文本编辑器默认编码：UTF-8
3. 当 UTF-8 文件在 GBK 环境运行 → 乱码

解决方案：
✅ 使用纯英文脚本（推荐）
✅ 或转换文件编码为 ANSI/GBK
✅ 或使用 PowerShell 替代 cmd
```

### Q2: 为什么要重启命令行？

**A**: 安装软件后，需要重启命令行才能刷新环境变量。

```
旧的命令行窗口 → 没有新的 PATH 变量 → 找不到命令
新的命令行窗口 → 有新的 PATH 变量 → 可以找到命令
```
