│    1. 访问：https://nodejs.org/                             │
│    2. 下载 LTS 版本（推荐）                                 │
│    3. 默认安装即可                                           │
│    4. 安装后重启命令行                                      │
│                                                               │
│  验证安装：                                                   │
│    打开新的命令行窗口，输入：                               │
│    python --version                                          │
│    node --version                                            │
