## 🚀 解决您的问题 - 3 步走

### 第 1 步：诊断环境

```bash
双击运行：check_environment.bat
```

**根据诊断结果**：

#### 情况 A：✅ 环境完整
```
✅ Python: 已安装
✅ Node.js: 已安装
✅ Poetry: 已安装

→ 运行 start.bat
```

#### 情况 B：⚠️ 缺少 Poetry
```
✅ Python: 已安装
✅ Node.js: 已安装
❌ Poetry: 未安装

→ 运行 start_simple.bat（无需 Poetry）
```

#### 情况 C：❌ 缺少 Python 或 Node.js
```
❌ Python: 未安装
或
❌ Node.js: 未安装

→ 按照诊断工具的提示安装缺失软件
```

---

### 第 2 步：安装缺失的软件（如果需要）

#### 安装 Python

```
1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.10 或更高版本
3. 运行安装程序
4. ⚠️ 重要：勾选 "Add Python to PATH"
5. 安装完成后，重启命令行
```

#### 安装 Node.js

```
1. 访问 https://nodejs.org/
2. 下载 LTS（长期支持）版本
3. 运行安装程序，默认选项安装
4. 安装完成后，重启命令行
```

#### 安装 Poetry（可选）

```powershell
# 打开 PowerShell（管理员模式）
# 运行：
(Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | python -

# 或者跳过此步，直接使用 start_simple.bat
```

---

### 第 3 步：启动系统

#### 方式 A：使用 start.bat（有 Poetry）

```bash
双击运行：start.bat

# 首次运行会自动安装依赖（需要几分钟）
# 之后会启动前后端服务
# 浏览器会自动打开
```

#### 方式 B：使用 start_simple.bat（无 Poetry）

```bash
双击运行：start_simple.bat

# 会自动创建虚拟环境
# 使用 pip 安装依赖
# 启动前后端服务
```

## 📋 常见问题速查

### Q1: 还是闪退怎么办？

```bash
# 手动运行，查看详细错误
# 1. 打开命令行（cmd）
# 2. 进入项目目录
cd 你的项目路径

# 3. 运行诊断
check_environment.bat

# 4. 查看错误信息，按提示操作
```

---

### Q2: Python 已安装但提示未找到？

**原因**：没有添加到 PATH

**解决**：
1. 重新安装 Python，勾选 "Add Python to PATH"
2. 或手动添加到系统环境变量
3. 重启命令行窗口

详见：[TROUBLESHOOTING.md - Python 问题](./TROUBLESHOOTING.md#问题-2-python-未安装或未找到)

---

### Q3: 依赖安装失败？

**可能原因**：
- 网络问题
- 防火墙拦截
- 镜像源问题

**解决**：
```bash
# 使用国内镜像
# Python:
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/

# Node.js:
npm config set registry https://registry.npmmirror.com

# 然后重新运行启动脚本
```

详见：[TROUBLESHOOTING.md - 依赖问题](./TROUBLESHOOTING.md#问题-5-依赖安装失败)

---

### Q4: 我不想配置环境，有更简单的方法吗？

**有！使用打包版**

```bash
# 1. 如果您的电脑已有 Python 和 Node.js（即使闪退）
#    可以运行打包脚本
build.bat

# 2. 等待打包完成（首次需要几分钟）

# 3. 双击运行生成的文件
dist\TmallGiftSnatcher.exe

# 这样就不需要每次都配置环境了！
```
