## 🚀 使用说明

### 1. 访问监控页面

```
URL: http://localhost:5173/monitor
导航: 点击顶部导航栏的"实时监控"
```

### 2. 启动监控任务

**步骤**:
1. 在"启动新监控"卡片中输入账号ID
2. 系统自动使用自适应监控（300ms-2s）
3. 点击"启动监控"按钮
4. 等待成功提示

**示例**:
```
账号ID: user_001
自动配置: 自适应监控 ✅
```

### 3. 查看监控状态

**实时数据**:
- 活跃监控数量
- 平均响应时间
- 总检查次数
- 状态变化次数

**监控列表**:
- 每个监控的详细信息
- 运行状态
- 响应速度等级
- 操作按钮（停止）

### 4. 启动健康检查

**步骤**:
1. 在右侧"会话健康"卡片
2. 点击"启动健康检查"
3. 自动开启24小时监控
4. 查看系统健康度

**功能**:
- 自动检查所有账号Cookie
- 检测过期和续期
- 实时健康度显示
- 即时统计更新

### 5. 立即检查所有账号

**步骤**:
1. 点击"立即检查所有账号"按钮
2. 等待检查完成（通常1-5秒）
3. 查看检查结果Toast提示

**结果显示**:
```
检查完成！健康: 8 | 异常: 2
耗时: 2.34秒
```

## 🔧 配置说明

### 监控配置

```typescript
// 自适应监控（推荐）
{
  account_id: "user_001",
  use_adaptive: true,  // 自动调整300ms-2s
}

// 固定间隔监控
{
  account_id: "user_001",
  check_interval: 0.5,  // 500ms固定间隔
  use_adaptive: false,
}

// 指定礼包监控
{
  account_id: "user_001",
  gift_ids: ["gift_001", "gift_002"],
  use_adaptive: true,
}
```

### 健康检查配置

```typescript
// 标准配置（推荐）
{
  check_interval: 3600,  // 每小时检查
  use_enhanced: true,    // 使用增强服务
}

// 高频检查
{
  check_interval: 1800,  // 每30分钟
  use_enhanced: true,
}

// 基础检查
{
  check_interval: 7200,  // 每2小时
  use_enhanced: false,   // 使用基础服务
}
```
