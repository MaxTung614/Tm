```
✅ 使用淘宝App扫码

✅ 更加安全便捷
```

### 2️⃣ Cookie登录
```
✅ 手动输入Cookie

✅ 适合开发调试
```

## 🔄 工作流程

### 完整流程

```
用户点击"扫码登录"
        ↓
  系统生成二维码
        ↓
  显示二维码 + 开始轮询
        ↓
  用户使用淘宝App扫码
        ↓
  检测到扫码 → 状态变为"已扫码"
        ↓
  用户在手机上确认登录
        ↓
  检测到确认 → 状态变为"扫码成功"
        ↓
  获取Cookie → 自动登录
        ↓
  跳转到主页
```

### 超时处理

```
倒计时: 3:00 → 2:59 → ... → 0:00
                              ↓
                         状态变为"已过期"
                              ↓
                        显示"刷新二维码"按钮
                              ↓
                        用户点击刷新
                              ↓
                        重新生成二维码
```

## 🎯 用户操作指南

### 扫码登录步骤

```
步骤1: 访问登录页面
       ↓
步骤2: 点击"扫码登录"标签
       ↓
步骤3: 等待二维码生成 (约1秒)
       ↓
步骤4: 打开手机淘宝App
       ↓
步骤5: 点击首页右上角"扫一扫"
       ↓
步骤6: 扫描屏幕上的二维码
       ↓
步骤7: 在手机上点击"确认登录"
       ↓
步骤8: 自动登录并跳转
```

### 注意事项

```
⚠️ 二维码有效期3分钟
⚠️ 过期需要点击刷新
⚠️ 必须使用官方淘宝App
⚠️ 确保网络连接正常
⚠️ 扫码后需在手机上确认
```

## 🔌 后端集成指南

### 需要实现的API

#### 1. 生成二维码接口

```python
POST /api/auth/qrcode/generate

响应:
{
  "success": true,
  "data": {
    "qrCodeUrl": "data:image/png;base64,iVBORw0KG...",
    "qrCodeId": "qr_1699612345",
    "expireTime": 180
  }
}
```

#### 2. 检查扫码状态接口

```python
GET /api/auth/qrcode/check?qr_id=qr_1699612345

响应 (未扫码):
{
  "success": true,
  "data": {
    "status": "waiting"
  }
}

响应 (已扫码):
{
  "success": true,
  "data": {
    "status": "scanned"
  }
}

响应 (已确认):
{
  "success": true,
  "data": {
    "status": "confirmed",
    "cookie": "cookie2=xxx; _m_h5_tk=xxx; ..."
  }
}
```
