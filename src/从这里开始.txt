========================================
  天猫礼享金抢购系统
  从这里开始 - 快速指南
========================================

重要提示：如果您在运行批处理文件时看到乱码，
         请使用英文版本（文件名带 _en 后缀的）

========================================
第 1 步：检查环境
========================================

双击运行：
    check_env_en.bat
    （英文版，避免乱码）

这会检查您是否安装了：
- Python 3.10+
- Node.js 18+
- Poetry（可选）

========================================
第 2 步：安装缺失的软件
========================================

如果缺少 Python：
1. 访问：https://www.python.org/downloads/
2. 下载 Python 3.10 或更高版本
3. 重要：安装时勾选 "Add Python to PATH"
4. 安装后重启命令行

如果缺少 Node.js：
1. 访问：https://nodejs.org/
2. 下载 LTS 版本
3. 默认安装即可
4. 安装后重启命令行

Poetry 是可选的：
- 有 Poetry：使用 start_en.bat
- 没有 Poetry：使用 start_simple_en.bat（推荐新手）

========================================
第 3 步：启动系统
========================================

选择以下一种方式：

方式 A：使用 Poetry
    双击运行：start_en.bat

方式 B：不使用 Poetry（更简单）
    双击运行：start_simple_en.bat

方式 C：打包成独立程序
    双击运行：build.bat
    然后运行：dist\TmallGiftSnatcher.exe

========================================
预期效果
========================================

运行启动脚本后：
1. 首次会安装依赖（5-10 分钟）
2. 会打开两个窗口：
   - 前端服务（Vite）
   - 后端服务（FastAPI）
3. 浏览器会自动打开：
   http://localhost:5173

========================================
常见问题
========================================

问题：脚本运行后立即关闭
解决：运行 check_env_en.bat 查看缺少什么

问题：提示 "Python not found"
解决：安装 Python 并勾选 "Add to PATH"
     安装后重启命令行

问题：提示 "Node not found"
解决：从 https://nodejs.org/ 安装 Node.js
     安装后重启命令行

问题：依赖安装失败
解决：检查网络连接
     国内用户可能需要配置镜像源

问题：端口被占用
解决：关闭占用 8000 或 5173 端口的程序
     或重启电脑
