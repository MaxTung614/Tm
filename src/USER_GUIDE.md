## 📱 系统简介

天猫礼享金抢购系统是一个自动化抢购工具，支持：
- ✅ 多账号管理
- ✅ 扫码登录

## 🎯 功能使用指南

![登录流程](./assets/login-flow.png)

---

### 2️⃣ 添加账号

#### 方式一：扫码添加

1. 进入"账号管理"页面
2. 点击"添加账号"
3. 扫描二维码登录
4. 系统自动保存 Cookie

#### 方式二：导入 Cookie

1. 点击"导入 Cookie"
2. 粘贴完整的 Cookie 字符串
3. 系统自动验证并保存

---

### 3️⃣ 配置风控参数

**重要**：风控参数是抢购成功的关键！

#### 自动提取（推荐）

```bash
# 方式 1：使用自动提取工具
cd tools
python auto_extract_params.py

# 方式 2：使用 UMID Token 提取器
python umid_token_extractor.py
```

#### 手动配置

编辑 `data/risk_params.json`：

```json
{
  "ua": "Mozilla/5.0 ...",
  "umidToken": "YOUR_UMID_TOKEN_HERE",
  "asac": "2A21B24LA1SI0HB0EEVN03"
}
```

**参数说明**：
- `ua`: 浏览器 User-Agent
- `umidToken`: 设备唯一标识（重要！）
- `asac`: 安全参数（已硬编码，可多账号共用）

---

### 4️⃣ 创建抢购任务

#### 步骤：

1. **进入任务管理**
   - 点击左侧菜单"任务管理"

2. **创建新任务**
   - 点击"创建任务"按钮
   - 填写任务信息：
     - 任务名称（如：每日 10 点抢购）
     - 选择账号
     - 选择礼品

3. **配置定时**
   - 设置执行时间（如：10:00:00）
   - 选择重复模式（每天/单次）

4. **启动任务**
   - 点击"启动"按钮
   - 系统将自动执行

## ❓ 常见问题解答

### Q1: 扫码登录失败？

**解决方案**：
```
1. 检查网络连接
2. 确认使用手机淘宝扫码
3. 检查后端服务是否启动
4. 查看控制台错误信息
```

### Q2: 抢购失败，提示风控参数错误？

**解决方案**：
```
1. 重新提取 UMID Token
2. 确保 UA 与登录设备一致
3. 使用最新的风控参数
4. 尝试更换设备
```

### Q3: Cookie 过期怎么办？

**解决方案**：
```
1. 账号管理 → 选择账号
2. 点击"刷新 Cookie"
3. 重新扫码登录
4. 系统自动更新
```

### Q4: 多个账号可以共用风控参数吗？

**答案**：
```
✅ 可以！
- ASAC 参数已硬编码，所有账号通用
- UA 和 UMID Token 建议每个设备一套
- 同一设备的多个账号可以共用
```

### Q5: 抢购速度太慢？

**优化建议**：
```
1. 使用定时任务（精确到毫秒）
2. 减少任务数量（避免并发冲突）
3. 优化网络环境（使用有线网络）
4. 提前 1-2 秒启动任务
```

### Q6: 如何查看日志？

**日志位置**：
```
- 后端日志：控制台输出
- 任务日志：任务管理 → 查看日志
- 错误日志：data/logs/ 目录
```

### Q7: 支持哪些操作系统？

**兼容性**：
```
✅ Windows 10/11
✅ macOS 10.15+
✅ Linux（Ubuntu/Debian）
```

### Q8: 打包版和开发版有什么区别？

**对比**：
```
打包版（.exe）：
- ✅ 一键启动

开发版（源码）：
```

## ⚠️ 注意事项

### 安全提醒

1. **账号安全**
   - ⚠️ 不要泄露 Cookie
   - ⚠️ 定期更换密码
   - ⚠️ 不要在公共网络使用

2. **风控风险**
   - ⚠️ 不要频繁抢购
   - ⚠️ 建议间隔 3-5 秒
   - ⚠️ 避免同一账号多设备登录

3. **合法使用**
   - ⚠️ 仅供个人学习研究
   - ⚠️ 不要用于商业用途
   - ⚠️ 遵守平台规则
