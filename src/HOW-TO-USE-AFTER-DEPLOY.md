## 🎯 两种登录的区别

### Supabase Auth 登录（系统登录）

| 项目 | 说明 |
|------|------|
| **用途** | 登录抢购系统本身 |
| **凭证** | 邮箱 + 密码 |
| **在哪里** | 登录页面（/login） |
| **管理** | Supabase Dashboard → Authentication |
| **作用** | 访问系统功能、管理账号、查看日志 |

### 淘宝账号登录（业务账号）

| 项目 | 说明 |
|------|------|
| **用途** | 抢购天猫红包 |
| **凭证** | Cookie（从淘宝扫码获取） |
| **在哪里** | 账号管理页面（/accounts） |
| **管理** | 添加/删除/更新淘宝账号 |
| **作用** | 调用天猫 API、获取红包、执行抢购 |

## ❓ 常见问题

### Q1: 为什么我登录了还是看不到红包？

**A**: 您登录的是系统（Supabase Auth），但还需要添加淘宝账号（Cookie）才能获取红包。

**解决**：
```
账号管理 → 添加账号 → 扫码登录淘宝
```

---

### Q2: 如何获取淘宝 Cookie？

**A**: 两种方式：

**方式 1：扫码登录（推荐）**
- 在"账号管理"页面点击"添加账号"
- 使用扫码登录组件
- 手机淘宝 App 扫码
- 系统自动获取 Cookie

**方式 2：浏览器手动提取**
1. 打开 https://www.taobao.com
2. 登录淘宝
3. F12 打开控制台
4. Application → Cookies → https://www.taobao.com
5. 复制所有 Cookie
6. 粘贴到"账号管理"页面

---

### Q3: Cookie 会过期吗？

**A**: 会的。淘宝 Cookie 通常 7-30 天过期。

**解决**：
```
账号管理 → 编辑账号 → 重新扫码/粘贴 Cookie
```

---

### Q4: 可以添加多个淘宝账号吗？

**A**: 可以！系统支持多账号。

**说明**：
- 每个淘宝账号可以单独抢购
- 多账号可以提高成功率
- 在"账号管理"中可以管理所有账号

---

### Q5: 如何知道 Cookie 是否有效？

**A**: 查看控制台日志或红包列表。

**有效的标志**：
- ✅ 红包中心显示11个红包
- ✅ 控制台显示 `[REAL] 获取到 XX 个可用红包`

**失效的标志**：
- ❌ 显示"请先添加账号"
- ❌ 控制台显示错误信息

---

### Q6: 抢购失败怎么办？

**A**: 检查以下几点：

1. **Cookie 是否有效**
   ```
   账号管理 → 查看账号状态
   ```

2. **红包是否可用**
   ```
   红包中心 → 检查红包状态
   ```

3. **查看错误日志**
   ```
   监控日志 → 查看详细错误信息
   ```

4. **重试**
   ```
   点击"重新抢购"按钮
   ```
