# 🎁 自动红包抢购使用指南

## 📱 关于设备绑定

### ⚠️ **重要：设备绑定说明**

**风控参数绑定规则：**

| 参数 | 设备绑定程度 | 说明 |
|------|------------|------|
| 🔴 **umidToken** | **强绑定** | 设备唯一标识，换设备必须重新提取 |
| 🟡 **ua** | 中等绑定 | 包含设备指纹，换设备可能失效 |
| 🟢 **cookies** | 账号绑定 | 只要同一账号就可以使用 |

---

### **✅ 推荐方案：固定设备**

**最佳实践：**
- 始终使用同一台手机扫码登录
- 不要频繁换设备
- 定期更新 cookies（1-7天）
- 定期更新 umidToken（7-30天）

---

### **⚠️ 如果必须换设备**

**步骤：**

1. **使用新手机扫码登录**
   ```bash
   # 启动系统
   python -m backend.main
   npm run dev
   
   # 访问登录页面，用新手机扫码
   ```

2. **重新提取风控参数**
   ```bash
   # 方法1：自动提取工具
   python tools/umid_token_extractor.py
   
   # 方法2：手机抓包
   # 参考 MOBILE_CAPTURE_GUIDE.md
   ```

3. **验证参数有效性**
   ```bash
   python tools/validate_params.py
   ```

4. **测试抢购功能**
   - 在前端点击"刷新"按钮
   - 尝试抢购一个小额红包
   - 查看是否成功

## 🚀 自动红包抢购功能

### **功能特点** ✨

✅ **自动加载**：打开页面自动获取所有可抢红包  
✅ **一键抢购**：点击"一键抢购"按钮，自动领取所有红包  
✅ **只显示红包**：过滤掉话费、商品券等，只显示现金红包  
✅ **实时更新**：点击"刷新"按钮实时获取最新红包列表

---

### **使用步骤** 📝

#### **第 1 步：启动系统**

```bash
# 终端1：启动后端
python -m backend.main

# 终端2：启动前端
npm run dev
```

#### **第 2 步：访问系统**

浏览器打开：**http://localhost:5173**

#### **第 3 步：查看红包列表**

- ✅ 系统会自动加载所有可抢红包
- ✅ 只显示现金红包（已过滤话费、商品等）
- ✅ 显示红包金额、ID、状态

#### **第 4 步：开始抢购**

**方法 1：一键抢购（推荐）** ⭐
```
点击右上角"一键抢购"按钮
→ 系统自动领取所有可抢红包
→ 查看抢购结果
```

**方法 2：单个抢购**
```
点击某个红包的"立即抢购"按钮
→ 系统抢购该红包
→ 成功后显示"已抢购"
```

## 🔧 故障排查

### **问题 1：没有显示红包**

**原因：**
- 后端未启动
- Cookie 过期
- 没有可用红包

**解决：**
1. 检查后端是否运行
2. 点击"刷新"按钮
3. 检查 Cookie 是否有效
4. 重新扫码登录

---

### **问题 2：抢购失败**

**常见错误码：**

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| **FAIL_SYS_ILLEGAL_ACCESS** | 风控参数失效 | 更新 umidToken 和 cookies |
| **库存不足** | 红包被抢完 | 等待新红包或刷新列表 |
| **未登录** | Cookie 过期 | 重新扫码登录 |
| **网络错误** | 网络问题 | 检查网络连接 |

**解决步骤：**

```bash
# 1. 更新 umidToken
python tools/umid_token_extractor.py

# 2. 验证参数
python tools/validate_params.py

# 3. 重启后端
# Ctrl+C 停止后端，然后重新启动
python -m backend.main

# 4. 刷新前端
# 在浏览器中点击"刷新"按钮
```

---

### **问题 3：一键抢购部分失败**

**说明：**
- 这是正常现象
- 可能部分红包被抢完
- 或者网络延迟

**查看结果：**
```
成功抢购 3 个红包，失败 2 个
```

**处理：**
- 查看日志了解失败原因
- 成功的红包已领取
- 失败的可以稍后重试

### **场景 2：定时监控**

```
1. 设置浏览器自动刷新（每5分钟）
2. 使用浏览器扩展或脚本
3. 自动调用"一键抢购"API
4. 监控抢购结果
```

**API 调用示例：**
```javascript
// 自动抢购脚本
setInterval(async () => {
  // 刷新列表
  await fetch('http://localhost:5000/api/gifts/list?type=redPacket');
  
  // 一键抢购
  const response = await fetch('http://localhost:5000/api/gifts/batch-grab', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ giftIds: ['all'] })
  });
  
  console.log('抢购结果:', await response.json());
}, 5 * 60 * 1000); // 每5分钟
```
