## 🚀 Step 1: 配置 Supabase（5分钟）

### 1.1 创建项目
1. 访问 [https://supabase.com](https://supabase.com)
2. 注册并创建项目（项目名: `tmall-gift-grabber`）
3. 等待 1-2 分钟

### 1.2 初始化数据库
1. 打开 **SQL Editor**
2. 复制 `/supabase-setup.sql` 全部内容
3. 粘贴并点击 **Run**
4. 看到 "Success" ✅

### 1.3 配置环境变量
1. 进入 **Settings** → **API**
2. 复制 **Project URL** 和 **anon public key**
3. 在 Figma Make 弹窗中输入

### 1.4 验证连接
启动应用，Dashboard 顶部应显示：
```
✅ Supabase 已连接
```

---

## 👥 Step 2: 添加第一个账号（2分钟）

### 2.1 访问 Accounts 页面
左侧导航栏 → **Accounts（账号管理）**

### 2.2 点击"添加账号"
右上角橙色按钮 → **"添加账号"**

### 2.3 填写信息

**测试账号（推荐首次使用）**:
```
账号名称: 测试账号
Cookie: test_cookie_123456
```

**或真实账号**:
```
账号名称: 主账号
Cookie: [从浏览器复制真实 Cookie]
```

### 2.4 保存
点击 **"保存"** 按钮

### 2.5 验证
- ✅ 看到提示: "账号添加成功"
- ✅ 页面显示新账号卡片
- ✅ 去 Supabase 确认记录存在

---

## 🎁 Step 3: 开始抢购（1分钟）

### 3.1 访问 Dashboard
左侧导航栏 → **Dashboard（首页）**

### 3.2 查看红包列表
系统会自动加载可抢红包（测试模式显示 11 个模拟红包）

### 3.3 开始抢购
- **单个抢购**: 点击红包卡片的 **"立即抢购"** 按钮
- **批量抢购**: 右上角 **"一键抢购"** 按钮

## 🆘 遇到问题？

### 连接失败
→ 检查环境变量是否正确
→ 参考 `/SUPABASE-SETUP.md` 第 3 步

### 账号添加失败
→ 检查 Dashboard 顶部连接状态
→ 参考 `/docs/HOW-TO-ADD-ACCOUNT.md`

### 抢购失败
→ 确认账号是激活状态
→ 确认 Cookie 未过期
