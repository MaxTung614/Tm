## 🐛 常见问题排查

### 问题 1: 扫码登录界面显示错误
**检查**:
- [ ] `/components/auth/QRCodeLogin.tsx` 是否存在
- [ ] `authService.generateQRCode()` 是否正常

### 问题 2: 红包列表为空
**检查**:
- [ ] 控制台是否有错误日志
- [ ] Mock 模式: `api-services.mock.ts` 中的 `TARGET_RED_PACKETS`
- [ ] Real 模式: 天猫 API 是否可访问

### 问题 3: 账号无法保存
**检查**:
- [ ] Supabase 是否已配置
- [ ] 数据库表是否已创建
- [ ] 环境变量是否正确

### 问题 4: Toast 不显示
**检查**:
- [ ] `<Toaster>` 组件是否在 `App.tsx` 中
- [ ] Sonner 库是否正确导入
