#### ✅ 功能 #1: Cookie 有效性验证

```typescript
// 在账号管理页面添加"验证 Cookie"按钮
async function validateCookie(cookie: string): Promise<boolean> {

    // 调用 mtop.user.getUserSimple 或类似接口

  }

```

**价值：**

#### ✅ 功能 #2: 用户昵称提取和显示

```typescript
// 从 Cookie 中提取昵称
function extractNickname(cookie: string): string | null {
  const nickMatch = cookie.match(/_w_tb_nick=([^;]+)/);
  return nickMatch ? decodeURIComponent(nickMatch[1]) : null;
}
```

**价值：**
- ✅ 界面更友好（显示"账号：张三"而不是长串 Cookie）
- ✅ 方便区分多个账号
- ✅ 提升用户体验

#### ✅ 功能 #3: 登录态定期检查

```typescript
// 定期检查 Cookie 是否过期
setInterval(async () => {
  const isValid = await validateCookie(cookies);
  if (!isValid) {
    showNotification('Cookie 已失效，请重新登录');
  }
}, 5 * 60 * 1000); // 每5分钟检查一次
```

**价值：**
- ✅ 主动发现 Cookie 失效
- ✅ 避免抢购时才发现问题
