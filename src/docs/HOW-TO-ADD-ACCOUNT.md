# 📘 如何添加测试账号

## 🎯 步骤概览

添加测试账号只需 **3 个简单步骤**：

1. 访问 **Accounts** 页面
2. 点击 **"添加账号"** 按钮
3. 填写信息并保存

---

## 📝 详细步骤

### 步骤 1: 访问 Accounts 页面

启动应用后，在左侧导航栏找到并点击 **"Accounts"（账号管理）**。

```
Dashboard（首页）
Monitor（监控）
Tasks（任务）
→ Accounts（账号管理）← 点击这里
ExtractParams（参数提取）
Settings（设置）
```

---

### 步骤 2: 点击"添加账号"按钮

在 Accounts 页面右上角，点击橙色的 **"添加账号"** 按钮。

```
┌─────────────────────────────────────────────┐
│ 👥 账号管理                 [刷新] [添加账号] │
│ 管理您的淘宝/天猫账号                          │
└─────────────────────────────────────────────┘
```

---

### 步骤 3: 填写信息并保存

#### 对话框会弹出，包含两个输入框：

**① 账号名称**
- 输入: `测试账号`（或任何您喜欢的名字）
- 示例: `主账号`、`小号1`、`测试用户`

**② Cookie 字符串**
- **测试模式**: 随便输入一些文本即可
  - 示例: `test_cookie_123456`
  - 示例: `cookie2=xxx; _m_h5_tk=xxx;`
  
- **真实模式**: 需要从浏览器获取真实 Cookie
  - 详见下方 "如何获取真实 Cookie"

#### 点击 **"保存"** 按钮

---

### 步骤 4: 验证成功

#### ✅ 成功标志：
1. 看到绿色提示: **"账号添加成功"**
2. 页面上出现新添加的账号卡片
3. 账号卡片显示:
   - 账号名称: `测试账号`
   - 状态徽章: `激活`
   - Cookie 前缀: `test_cookie_1...`

#### ✅ 在 Supabase 中验证：
1. 打开 [Supabase Dashboard](https://supabase.com/dashboard)
2. 进入您的项目
3. 点击 **Table Editor** → **accounts** 表
4. 应该能看到刚刚添加的记录

---

## 🔐 如何获取真实 Cookie

如果您要使用真实的天猫账号，需要从浏览器获取 Cookie：

### 方法 1: 使用 Chrome 开发者工具

1. **打开淘宝/天猫**
   - 访问 [https://www.taobao.com](https://www.taobao.com)
   - 确保已登录

2. **打开开发者工具**
   - 按 `F12` 键
   - 或右键点击页面 → 选择"检查"

3. **切换到 Application 标签**
   - 点击顶部的 **"Application"** 标签
   - 如果找不到，点击 `>>` 查看更多标签

4. **查看 Cookies**
   - 左侧展开 **Storage** → **Cookies**
   - 点击 `https://www.taobao.com`

5. **复制所有 Cookie**
   - 选择所有 Cookie 行
   - 右键 → **Copy all as cURL**
   - 或手动复制关键 Cookie: `cookie2`, `_m_h5_tk`, `_tb_token_`

### 方法 2: 使用 Network 标签

1. 打开开发者工具（F12）
2. 切换到 **Network** 标签
3. 刷新页面（F5）
4. 点击任意请求
5. 找到 **Request Headers** 中的 **Cookie**
6. 复制整个 Cookie 字符串

## 🧪 测试 vs 真实模式

### 🟦 测试模式（推荐用于验证连接）

**用途**: 验证 Supabase 连接是否正常

**Cookie 示例**:
```
test_cookie_123456
```

**特点**:
- ✅ 快速测试数据库连接
- ✅ 验证添加/删除/编辑功能
- ❌ 无法进行真实抢购

---

### 🟩 真实模式（用于实际抢购）

**用途**: 真实的红包抢购

**Cookie 示例**:
```
cookie2=1234567890abcdef; _m_h5_tk=1a2b3c4d5e6f; _tb_token_=e3b4f5g6h7i8; ...
```

**特点**:
- ✅ 可以进行真实抢购
- ✅ 自动获取天猫红包列表
- ⚠️ Cookie 会过期，需要定期更新

---

## 📊 账号管理功能

添加账号后，您可以：

### 1. **激活/停用账号**
- 点击卡片上的 **"停用"** 或 **"激活"** 按钮
- 停用的账号不会参与抢购

### 2. **编辑账号**
- 点击 **铅笔图标** 按钮
- 修改账号名称或 Cookie

### 3. **删除账号**
- 点击 **垃圾桶图标** 按钮
- 确认后永久删除（无法恢复）

### 4. **查看 Cookie 状态**
- Cookie 前 40 个字符会显示
- 完整 Cookie 已加密存储在 Supabase

## 🔍 故障排除

### 问题 1: 点击"添加账号"没有反应

**原因**: JavaScript 错误或页面未加载完成

**解决**:
1. 刷新页面（F5）
2. 检查浏览器控制台是否有错误
3. 确认 Supabase 连接正常

---

### 问题 2: 保存时提示"请输入 Cookie"

**原因**: Cookie 输入框为空

**解决**:
1. 在 Cookie 输入框中输入内容
2. 测试模式: 随便输入一些文本
3. 真实模式: 参考上方"如何获取真实 Cookie"

---

### 问题 3: 保存成功但 Supabase 中没有数据

**原因**: Supabase 连接配置错误

**解决**:
1. 检查 Dashboard 顶部的连接状态
2. 如果显示红色，说明 Supabase 未连接
3. 参考 `/SUPABASE-SETUP.md` 重新配置

---

### 问题 4: Cookie 过期了怎么办？

**原因**: Cookie 有时效性，通常 1-7 天

**解决**:
1. 重新从浏览器获取 Cookie
2. 点击账号的 **"编辑"** 按钮
3. 更新 Cookie 字符串
4. 保存
