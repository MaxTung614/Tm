## 🔧 系统实现

### 统一常量定义
所有目标红包在 `/lib/constants.ts` 中统一定义和管理：

```typescript
export const TARGET_RED_PACKETS = [
  '4a7c9e8c194046de951c87ac3187e325', // 800元红包
  '2713305bd3794de5aede654a29a095c5', // 500元红包
  // ... 其他9个红包
];
```

### 自动过滤机制
系统在以下环节自动过滤红包：

1. **Dashboard 页面** (`/pages/Dashboard.tsx`)
   - 加载红包列表时自动过滤
   - 刷新时自动过滤
   - 显示时按优先级排序

2. **抢购 Hook** (`/lib/usePurchase.ts`)
   - `getRedPackets()` - 获取红包时自动过滤和排序
   - `purchaseNow()` - 抢购前验证红包是否在目标列表中

3. **任务管理** (`/pages/Tasks.tsx`)
   - 只显示目标红包的抢购任务
   - 只允许创建目标红包的定时任务

### 辅助函数

```typescript
// 检查是否为目标红包
isTargetRedPacket(benefitCode: string): boolean

// 过滤出目标红包
filterTargetRedPackets<T>(packets: T[]): T[]

// 按优先级排序
sortRedPacketsByPriority<T>(packets: T[]): T[]

// 获取红包信息
getRedPacketInfo(benefitCode: string): RedPacketInfo | null
```

## 📊 统计与监控

系统的所有统计和监控都仅针对这11个红包：

- **累计抢购数** - 只统计目标红包
- **成功率** - 只计算目标红包的成功率
- **礼享金总额** - 只累计目标红包的金额
- **今日抢购** - 只统计今日抢购的目标红包

## ⚠️ 重要说明

1. **严格限制**：系统设计为只支持这11个红包，任何尝试抢购其他红包的操作都会被拒绝

2. **自动过滤**：所有从天猫API获取的红包列表都会自动过滤，只保留这11个

3. **优先级排序**：红包按照优先级（金额从大到小）自动排序显示

4. **数据验证**：在抢购前会验证 benefitCode 是否在目标列表中

## 🔄 更新红包列表

如果需要更新目标红包列表，请修改 `/lib/constants.ts` 中的 `TARGET_RED_PACKETS` 和 `RED_PACKET_INFO`。

系统会自动应用新的配置到所有功能模块。
