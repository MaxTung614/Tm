## 🎯 快速命令

### 安装依赖

```bash
npm install @supabase/supabase-js crypto-js
npm install --save-dev @types/crypto-js
```

### 配置环境变量

```bash
# 复制模板
cp .env.local.example .env.local

# 编辑文件，填写：
# VITE_SUPABASE_URL=...
# VITE_SUPABASE_ANON_KEY=...
# VITE_ENCRYPTION_KEY=...
```

### 启动应用

```bash
npm run dev
```

访问 http://localhost:5173

## 💡 核心优势

### vs 本地部署

| 本地部署 | Supabase 方案 |
|---------|--------------|
| ❌ 需要 Python 3.10+ | ✅ 只需浏览器 |
| ❌ 需要启动后端 | ✅ 无需后端 |
| ❌ 配置复杂 | ✅ 30分钟完成 |
| ❌ 不能跨设备 | ✅ 任何设备访问 |
| ❌ 数据不同步 | ✅ 实时云端同步 |
| ❌ 难以分享 | ✅ 一个链接即可 |

### 核心特性

- ✅ **完全无后端** - 告别 Python 环境配置
- ✅ **云端存储** - Cookie 加密存储在 Supabase
- ✅ **跨设备同步** - 家里、公司、手机都能用
- ✅ **实时更新** - Supabase Realtime 支持
- ✅ **完全免费** - Supabase 免费层足够
- ✅ **易于部署** - 可部署到 Vercel/Netlify
