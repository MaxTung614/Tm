## 🗄️ 数据库表结构

### 1. accounts（账号表）
```sql
- id: UUID (主键)
- name: VARCHAR(100) - 账号名称
- cookie: TEXT - 加密的 Cookie
- is_active: BOOLEAN - 是否激活
- created_at: TIMESTAMP
- updated_at: TIMESTAMP
```

**用途**: 安全存储用户的淘宝/天猫 Cookie

### 2. risk_params（风控参数表）
```sql
- id: UUID (主键)
- ua: TEXT - User Agent
- umid_token: TEXT - 设备唯一标识
- asac: VARCHAR(50) - 固定值
- created_at: TIMESTAMP
- updated_at: TIMESTAMP
```

**用途**: 存储浏览器指纹，通过天猫风控检测

### 3. purchase_tasks（抢购任务表）
```sql
- id: UUID (主键)
- account_id: UUID - 关联账号
- benefit_code: VARCHAR(100) - 红包编码
- amount: INTEGER - 红包金额
- scheduled_time: TIMESTAMP - 执行时间
- status: VARCHAR(20) - 任务状态
- result: JSONB - 执行结果
- created_at: TIMESTAMP
- updated_at: TIMESTAMP
```

**用途**: 管理定时抢购任务，支持自动调度

### 4. purchase_logs（操作日志表）
```sql
- id: UUID (主键)
- task_id: UUID - 关联任务
- account_id: UUID - 关联账号
- level: VARCHAR(10) - 日志级别
- message: TEXT - 日志消息
- details: JSONB - 详细信息
- created_at: TIMESTAMP
```

**用途**: 记录所有操作历史，方便调试和审计

## 🔒 安全说明

### ✅ 安全措施

1. **Cookie 加密存储** - 敏感数据加密后存储在 Supabase
2. **环境变量隔离** - API 密钥通过环境变量管理
3. **RLS 已禁用** - 简化个人使用，适合单用户场景
4. **只用 anon key** - 不泄露 service_role key

### ⚠️ 注意事项

1. **这是个人工具** - 仅适合您自己使用
2. **不要分享 Cookie** - Cookie 包含您的登录凭证
3. **定期更新 Cookie** - Cookie 会过期，需要重新扫码
4. **监控使用量** - 免费计划有 500MB 限制
