# 快速开始指南

## 📦 安装依赖

### 1. Python 环境 (3.10+)
```bash
# 安装 Poetry
pip install poetry

# 安装 Python 依赖
poetry install
```

### 2. Node.js 环境 (18+)
```bash
# 安装前端依赖
npm install
```

## 🚀 启动系统

### Windows 用户
```bash
# 双击运行（推荐）
start.bat

# 或使用英文版启动脚本（避免编码问题）
start_en.bat
```

### Linux/Mac 用户
```bash
# 使用 Python 启动
python launcher.py
```

## 🔐 首次使用

1. 系统启动后会自动打开浏览器访问 `http://localhost:5173`
2. 点击"扫码登录"获取淘宝 Cookie
3. 使用手机淘宝扫描二维码完成登录
4. 系统会自动提取并保存设备参数

## 📱 多账号管理

1. 进入"账号管理"页面
2. 点击"添加账号"
3. 扫码登录新账号
4. 切换不同账号进行操作

## 🎯 开始抢购

1. 进入"礼品大厅"
2. 浏览可抢购的礼品
3. 点击"立即抢购"或"创建定时任务"
4. 查看抢购结果

详细使用说明请查看 [完整用户指南](./USER_GUIDE.md)
