## 🚀 方式一：打包版（3 步完成）

---

### 第 2 步：提取风控参数（首次必做）⚠️

**为什么要提取？**
- 风控参数是抢购的"通行证"
- 没有它，抢购会失败
- 每个设备需要提取一次

**怎么提取？**

#### 方法 A：全自动（最简单）🌟

```
1. 在网页中点击 "设置" → "参数提取"
2. 点击 "自动提取" 按钮
3. 按照提示在手机淘宝 APP 中随便打开一个商品
4. 等待提取完成（约 30 秒）
5. 看到"提取成功"提示
```

#### 方法 B：手动提取

```
1. 电脑浏览器打开 www.taobao.com 并登录
2. 按键盘 F12 键（打开开发者工具）
3. 点击顶部的 "Network"（网络）标签
4. 刷新页面（按 F5）
5. 在列表中找任意一个 "mtop" 开头的请求
6. 点击它，查看 "Headers"（请求头）
7. 找到并复制:
   - User-Agent（通常很长）
   - umidToken（在 Cookie 中或请求头中）
8. 在网页的 "设置" 中粘贴这些参数
9. 点击 "保存"
```

**验证是否成功**:
```
设置 → 参数管理 → 点击"验证参数"
看到 ✅ 全部有效 即成功！
```

---

### 第 3 步：开始抢购

#### 3.1 添加账号

```
1. 点击左侧菜单 "账号管理"
2. 点击右上角 "添加账号"
3. 用手机淘宝扫描二维码
4. 等待登录成功
5. 账号自动保存
```

**提示**: 可以添加多个账号，提高中签率！

#### 3.2 创建任务

```
1. 点击左侧菜单 "任务管理"
2. 点击右上角 "创建任务"
3. 填写信息:
   - 任务名称: 随便填（如：早上 10 点抢购）
   - 选择账号: 勾选要用的账号
   - 选择礼品: 选择要抢的礼享金
   - 执行时间: 10:00:00（抢购开始时间）
   - 重复: 可选"每天"或"单次"
4. 点击 "创建"
```

#### 3.3 启动任务

```
1. 在任务列表中找到刚创建的任务
2. 点击任务右侧的 "启动" 按钮
3. 看到状态变为 "运行中"
4. 等待到达设定时间，系统自动抢购！
```

#### 3.4 查看结果

```
1. 点击左侧菜单 "仪表盘"
2. 查看:
   - 今日抢购次数
   - 成功次数
   - 成功率
3. 或在 "任务管理" 中查看任务执行日志
```

```
Windows PowerShell (管理员模式):
(Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | python -

Linux/Mac:
curl -sSL https://install.python-poetry.org | python3 -

验证安装:
poetry --version
```

## 🎯 使用技巧

### 1. 提高成功率

```
✅ 添加 3-5 个账号（同时抢购）
✅ 提前 1-2 秒启动任务
✅ 使用有线网络（不要用 WiFi）
✅ 关闭其他占网速的程序
✅ 选择人少的时间段
```

### 2. 避免被限制

```
⚠️ 不要频繁抢购（间隔 3-5 秒）
⚠️ 不要同一账号多设备同时登录
⚠️ 定期更换风控参数
⚠️ 不要一天抢太多次
```

### 3. 定时任务设置

```
抢购开始前 1 秒触发:
如果 10:00:00 开始，设置为 09:59:59

精确到毫秒:
可以设置为 09:59:59.500（需要在高级设置中）

重复任务:
选择"每天"，系统会每天自动执行
```

## ❓ 新手常见问题

### Q: 完全不懂编程，能用吗？

**A**: 能！选择打包版（方式一），只需要：
1. 下载 .exe 文件
2. 双击运行
3. 按照页面提示操作

---

### Q: 风控参数是什么？为什么要提取？

**A**: 
- 风控参数就像你的"身份证"
- 淘宝用它来识别你的设备
- 没有它，淘宝会认为你是机器人，拒绝抢购
- 每个设备提取一次就行，以后可以一直用

---

### Q: 提取风控参数失败怎么办？

**A**: 尝试以下方法：
1. 换一个浏览器（推荐 Chrome）
2. 清除浏览器缓存后重试
3. 使用手动提取方法
4. 检查网络连接是否正常

---

### Q: Cookie 是什么？会不会泄露账号？

**A**:
- Cookie 是登录凭证，就像"门禁卡"
- 系统会加密保存，只存在你电脑上
- 不会上传到任何服务器
- 定期更新即可（重新扫码登录）

---

### Q: 抢购一直失败？

**A**: 检查清单：
- [ ] 风控参数是否正确？（设置 → 验证参数）
- [ ] Cookie 是否过期？（账号管理 → 刷新 Cookie）
- [ ] 网络是否正常？
- [ ] 商品是否还有库存？
- [ ] 任务设置的时间是否正确？

---

### Q: 支持多个账号吗？

**A**: 
- ✅ 支持！
- 可以添加无限个账号
- 所有账号可以同时抢购
- 大大提高中签率
