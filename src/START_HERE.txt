========================================
  Tmall Gift Snatcher System
  START HERE - Quick Guide
========================================

IMPORTANT: If you see garbled text in Chinese scripts,
           use the English versions (_en.bat files)

========================================
STEP 1: Check Your Environment
========================================

Double-click to run:
    check_env_en.bat

This will check if you have:
- Python 3.10+
- Node.js 18+
- Poetry (optional)

========================================
STEP 2: Install Missing Software
========================================

If Python is missing:
1. Visit: https://www.python.org/downloads/
2. Download Python 3.10 or higher
3. IMPORTANT: Check "Add Python to PATH" during installation
4. Restart command prompt

If Node.js is missing:
1. Visit: https://nodejs.org/
2. Download LTS version (recommended)
3. Install with default settings
4. Restart command prompt

Poetry is optional:
- If you have it: Use start_en.bat
- If you don't: Use start_simple_en.bat (recommended for beginners)

========================================
STEP 3: Start the System
========================================

Choose ONE of the following:

Option A: With Poetry
    Double-click: start_en.bat

Option B: Without Poetry (Simpler)
    Double-click: start_simple_en.bat

Option C: Build Standalone .exe
    Double-click: build.bat
    Then run: dist\TmallGiftSnatcher.exe

========================================
WHAT TO EXPECT
========================================

When you run the start script:
1. Dependencies will be installed (first time only, takes 5-10 minutes)
2. Two windows will open:
   - Frontend (Vite dev server)
   - Backend (FastAPI server)
3. Your browser will open automatically at:
   http://localhost:5173

========================================
TROUBLESHOOTING
========================================

Problem: Script closes immediately
Solution: Run check_env_en.bat to see what's missing

Problem: "Python not found"
Solution: Install Python and check "Add to PATH"
         Restart command prompt after installation

Problem: "Node not found"
Solution: Install Node.js from https://nodejs.org/
         Restart command prompt after installation

Problem: Dependencies installation fails
Solution: Check your internet connection
         Try using a VPN if in China

Problem: Port already in use
Solution: Close other programs using port 8000 or 5173
         Or restart your computer
